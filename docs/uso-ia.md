# Utilización de la Inteligencia Artificial

En este documento se especifica que uso se le dio a la Inteligencia Artificial para la realización del proyecto. 

Hubo dos etapas del proyecto en las que se utilizó, que pasarán a desarrollarse a continuación.

### Etapa de Diseño

Para lograr un mejor entendimiento de la consigna, se interactuó con inteligencia artificial para tratar de comprender mas sencillamente los requerimientos del proyecto, ya que en un principio la información es muy **abrumadora**. Nos dio una buena base de la que pudimos partir.

### Etapa de Desarrollo

**Se diferencian dos tipos de usos entre el grupo:**

 - Algunos no utilizaron para nada la IA.
 - Y algunos otros usaron en ciertas ocasiones la herramienta que Copilot que autocompleta el código a medida que se va escribiendo para agilizar.
